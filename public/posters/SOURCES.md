# Poster image sources

These poster images were downloaded by a one-off script so the demo catalogue
has real film artwork with no API key and no network access. Each file is named
after its catalogue id in `src/data/movies.js` (`<id>.jpg`).

## Licensing

> **These are copyrighted film posters.** They are the low-resolution images
> used on Wikipedia film articles under fair use / fair dealing for
> identification and critical commentary. They are included here purely as
> artwork for a private, non-commercial demo project.
>
> **Do not redistribute or publish this folder as-is.** If you deploy this site
> publicly, replace these files with artwork you have the right to use (an
> official press kit, a licensed API such as TMDB), or delete the folder: the
> site then falls back to its own generated artwork automatically.
